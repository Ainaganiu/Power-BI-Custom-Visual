# Bar Chart Race

Turn your time-series data into an animated ranked bar chart — the "racing bars" format that makes rising and falling trends instantly watchable. Categories grow, shrink, and swap places as the timeline plays, with rank-change badges, a live leader subtitle, and a scrubbable timeline.

![Bar Chart Race in action](<!-- image URL here -->)

Every color inherits from your report theme by default — data colors, sentiment colors, foreground, background — so it fits any themed report without configuration, while still meeting WCAG contrast requirements. Override any color individually when you want full control.

**Highlights**
- Smooth, themable animation with adjustable speed, easing, and playback direction
- Cumulative or per-period racing modes
- Rank-change indicators (▲ ▼ ● ★) with independent colors
- Custom tooltip card with a live percent-of-total bar, or fall back to the native Power BI tooltip
- Full keyboard navigation and high-contrast mode support
- Native font controls on every text element
